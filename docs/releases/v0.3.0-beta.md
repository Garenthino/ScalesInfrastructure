## Scales 0.3.0 Beta

**Release date:** 2026-09-12

### Highlights

- Public beta portal deployed to https://dancingdragonservices.com.
- Marketing pages (homepage, features, pricing, contact, help, affiliates, sales portal) are live.
- /download page with Android release and Windows/Linux/macOS beta waitlist.
- Backend license API and admin portal for desktop license management.
- Android Play Store + APK fallback release automation.
- Desktop in-app auto-update and offline/online license activation.

### Compatibility

- Backend / Portal: `0.3.0`
- Mobile Android: `0.3.0+1`
- Desktop KJ: `0.3.0`

Mobile and desktop `0.3.x` are supported against backend `0.3.x`. See `docs/RELEASE_POLICY.md`.

### Known limitations

- Desktop installers are unsigned in this beta.
- Stripe collection is gated pending live account verification.
- macOS beta is deferred until code signing and notarization are ready.

### Deploy verification

- `GET /health` returns 200 with version `0.3.0`.
- Public pages return 200.
- License API endpoints are responsive.
